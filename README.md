# Roadmap World

A game-like 3D world map for an app roadmap. The island starts grey. Each time the user completes a step, their traveller walks the road to the next region, which then floods with colour while trees, houses, a windmill, a lighthouse and finally a golden city grow out of the ground. Unlocked regions stay alive: villagers wander, sheep graze, a boat circles the island, clouds drift and there's a day/night mode.

**Live demo:** https://ipayemichaelng.github.io/roadmap-world/ (works on a phone too)

Built with [Three.js](https://threejs.org) (MIT) and [GSAP](https://gsap.com) (free for commercial use). All scenery is generated in code from simple shapes, so there are no asset files.

## What's in here

| Path | What it is |
|---|---|
| `react-native/RoadmapWorld.tsx` | **Drop-in React Native component.** Renders the world in a WebView and talks to it over messages. |
| `react-native/roadmapWorldHtml.ts` | The whole player (engine + three.js + GSAP) as one HTML string, so it works offline. Generated by `npm run build`. Don't edit by hand. |
| `react-native/example/RoadmapScreen.tsx` | Example screen showing how the app drives progress. |
| `src/engine.js` | The engine: `createRoadmapWorld(container, options)`. Framework-agnostic, also usable directly in a web app. |
| `src/webview-entry.js` | Message bridge used inside the WebView. Opened in a normal browser, it runs a sample journey. |
| `scripts/build.mjs` | Bundles everything into `dist/roadmap-world.html`, `docs/index.html` (the GitHub Pages demo) and `react-native/roadmapWorldHtml.ts`. |
| `demo/concept-page.html` | The original concept page, including notes on alternative engines (Phaser, PixiJS, Babylon, PlayCanvas) and free art (Kenney, Quaternius). |

## Using it in React Native

1. Install the WebView (Expo: `npx expo install react-native-webview`, bare RN: `npm i react-native-webview && cd ios && pod install`).
2. Copy the `react-native/` folder into the app (for example `src/components/roadmap-world/`).
3. Render it:

```tsx
import { RoadmapWorld } from './roadmap-world/RoadmapWorld';

<RoadmapWorld
  steps={[
    { title: 'Eden Garden', subtitle: 'Genesis 2' },
    { title: "Jacob's Well", subtitle: 'John 4' },
    { title: 'Shepherd Hills', subtitle: 'Psalm 23' },
    { title: 'Bethlehem', subtitle: 'Luke 2' },
    { title: 'New Jerusalem', subtitle: 'Revelation 21' },
  ]}
  progress={completedCount}            // from your store / backend
  onRegionUnlocked={(i) => analytics.track('region_unlocked', { i })}
  onFinish={() => showCelebration()}
/>
```

The app owns the progress number. **Increase `progress` by exactly 1** and the map plays the walk-and-unlock animation. Any other change (first load, reset, syncing from another device) jumps straight to that state with no animation. Tip: if the user finished a step on another screen, mount the map with the old value and bump it once the screen is visible, so they see the unlock.

### Props

| Prop | Type | Default | Notes |
|---|---|---|---|
| `steps` | `{ title, subtitle?, kind? }[]` | required | 2–12 steps. The island layout adapts to the count. The last step is always the summit city. |
| `progress` | `number` | required | Completed steps, `0…steps.length`. |
| `hud` | `boolean` | `true` | Built-in quest card and region counter. Turn off if you draw your own UI on top. |
| `controls` | `boolean` | `false` | Built-in demo buttons. Leave off in production. |
| `night` | `boolean` | `false` | Animated day/night switch. |
| `theme` | `{ accent, accentDeep, gold, hero, heroHat }` | green/gold | Hex colours for buttons, progress bar, golden road and the traveller. |
| `rewardText` | `string \| null` | `'+10 XP'` | Floating text on completion. `{n}` = step number. `null` hides it. |
| `onReady`, `onStepComplete(i)`, `onRegionUnlocked(i)`, `onFinish()`, `onError(msg)` | callbacks | | |

`kind` picks the scenery for a region: `garden`, `well`, `hills`, `village`, `shore`, `gate` or `summit`. By default they cycle in that order.

There's also an imperative handle via `ref`: `completeStep()`, `setProgress(n)`, `setNight(on)`, `setOverview(on)`, `reset()`.

### Gestures

One-finger drag rotates the camera. Pinch zooms. The camera follows the traveller and slowly orbits when idle. "Overview" pulls back to show the whole island.

## Using it on the web

```js
import { createRoadmapWorld } from './src/engine.js';

const world = createRoadmapWorld(document.getElementById('map'), { steps, progress: 2 });
world.completeStep();   // animate the next step
world.setProgress(5);   // jump
world.destroy();        // on unmount
```

The container needs a size (for example `height: 70vh`).

## Notes for production

- **Performance:** a single WebGL scene at up to 2× pixel ratio, with shadows. Smooth on recent phones. On low-end Android, consider lowering `setPixelRatio` and the shadow map size in `src/engine.js`.
- **Accessibility:** a 3D canvas isn't readable by screen readers. Offer a plain list view of the same steps next to it.
- **Reduced motion:** if the OS "reduce motion" setting is on, the map skips walking, particles and ambient movement and changes state instantly.
- **Better art:** swap the code-built shapes for free CC0 models from [Kenney](https://kenney.nl/assets) or [Quaternius](https://quaternius.com) (load them with three's `GLTFLoader`) for a much richer look.
- **Going fully native later:** the same scene can be ported to `@react-three/fiber/native` with `expo-gl` if the WebView ever becomes a limitation.
